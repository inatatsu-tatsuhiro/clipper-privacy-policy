Clipper

運営者: 稲垣達大 (Tatsuhiro Inagaki) · 連絡先: info@inatatsu.dev

Clipper は、運営者が自分で運営する YouTube の切り抜きチャンネルに、短い切り抜き動画を投稿するための社内用デスクトップアプリです。一般には公開しておらず、運営者以外はログインしません。

Clipper is an internal desktop application that the operator uses to publish short clip videos to the YouTube channels it owns and operates. It is not available to the public.

主な機能 / Features

  • YouTube API サービスで、運営者のチャンネルに動画を予約投稿する / Scheduled uploads to the operator's own channels via YouTube API Services
  • タレント別の再生リストを作り、投稿した動画を追加する / Adds each upload to a per-talent playlist on the same channel
  • アプリの「連携を解除」で Google のアクセス許可を取り消し、保存データを削除する / "Disconnect" revokes Google access and deletes stored data

本アプリを使うことで、利用者は YouTube 利用規約 に同意したものとみなします。データの扱いには Google プライバシーポリシー が適用されます。
