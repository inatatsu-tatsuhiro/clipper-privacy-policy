プライバシーポリシー

Clipper / 運営者: 稲垣達大 / 制定日: 2026 年 10 月 2 日

1. このアプリについて

Clipper (以下「本アプリ」) は、稲垣達大が自分で運営する YouTube の切り抜きチャンネルに動画を投稿するための、社内用のデスクトップアプリです。本アプリが操作するのは運営者自身のチャンネルだけで、第三者のユーザーがログインしたり、第三者のチャンネルを操作したりすることはありません。

2. YouTube API サービスの利用

本アプリは YouTube API サービス (YouTube Data API v3) を使い、次のことを行います。

  • 運営者のチャンネルへの動画のアップロード (予約公開の設定を含む)
  • 運営者のチャンネルの再生リストの確認・作成と、再生リストへの動画の追加
  • ログインしたチャンネルの確認 (チャンネル名の取得)

本アプリを使うことで、利用者は YouTube 利用規約 に同意したものとみなします。YouTube API サービスを通じて扱われるデータには Google プライバシーポリシー が適用されます。

使用する権限 (OAuth スコープ)

スコープ使う目的
https://www.googleapis.com/auth/youtube.upload動画のアップロード
https://www.googleapis.com/auth/youtube.readonlyログインしたチャンネル名と、既存の再生リストの確認
https://www.googleapis.com/auth/youtube再生リストの作成と、再生リストへの動画の追加

3. 取得・保存するデータ

本アプリが保存するデータは、すべて運営者のパソコンの中だけにあり、本アプリの運営者のサーバーや第三者には送りません。

データ保存場所と方法保存する期間
Google のアクセス許可 (OAuth のリフレッシュトークン)運営者のパソコンに、OS のキーチェーンで暗号化して保存連携を解除するまで
本アプリが作成・使用した再生リストの ID運営者のパソコン連携を解除するまで (解除時に削除)
アップロードした動画の ID・URL・タイトル・予約公開の時刻・公開設定運営者のパソコン (投稿の記録として)運営者がアプリで記録を削除するまで
その日の API の使用量 (回数)運営者のパソコン日付が変わると上書き

ログインしたチャンネルの名前は、ログインできたことの確認に表示するだけで保存しません。本アプリは、視聴者や他のチャンネルの個人情報を取得しません。Cookie やアクセス解析は使いません。

アップロードが終わったことと動画の URL を、運営者自身が管理する Discord サーバーに通知することがあります。これ以外にデータを外部へ送ることはありません。

4. 連携の解除とデータの削除

  • 本アプリの設定画面の「連携を解除」で、Google 側のアクセス許可を取り消し、保存したリフレッシュトークンと再生リストの ID をすぐに削除します。
  • 本アプリを使わずに、Google アカウントのアクセス設定 から本アプリの許可を取り消すこともできます。
  • 投稿の記録は、本アプリの投稿画面からいつでも削除できます。
  • データの削除を依頼された場合は、遅くとも 30 日以内に削除します。

Privacy Policy

Clipper / Operator: Tatsuhiro Inagaki (稲垣達大) / Effective date: October 2, 2026

1. About this app

Clipper ("the App") is an internal desktop tool that Tatsuhiro Inagaki uses to publish videos to the YouTube clip channels it operates itself. The App only accesses the operator's own channels. No third-party users sign in to the App, and the App does not access any third-party channel.

2. Use of YouTube API Services

The App uses YouTube API Services (YouTube Data API v3) to:

  • upload videos to the operator's channels, including scheduled publishing;
  • list and create playlists on the operator's channels and add videos to them;
  • confirm which channel was signed in (channel title).

By using the App, users agree to be bound by the YouTube Terms of Service. Data handled through YouTube API Services is subject to the Google Privacy Policy.

OAuth scopes

ScopePurpose
https://www.googleapis.com/auth/youtube.uploadUploading videos
https://www.googleapis.com/auth/youtube.readonlyReading the signed-in channel title and existing playlists
https://www.googleapis.com/auth/youtubeCreating playlists and adding videos to them

3. Data collected and stored

All data is stored only on the operator's own computer. It is never sent to a server run by the operator or to any third party.

DataWhere and howRetention
Google authorization (OAuth refresh token)Operator's computer, encrypted with the OS keychainUntil access is revoked
IDs of playlists the App created or usedOperator's computerUntil access is revoked (deleted on revocation)
ID, URL, title, scheduled publish time and privacy setting of uploaded videosOperator's computer, as a posting logUntil the operator deletes the record in the App
Daily API usage countOperator's computerOverwritten every day

The signed-in channel title is only displayed to confirm the sign-in and is not stored. The App does not collect personal information about viewers or other channels, and uses no cookies or analytics.

The App may notify the operator's own Discord server that an upload finished, including the video URL. No other data leaves the operator's computer.

4. Revoking access and deleting data

  • "連携を解除" (Disconnect) in the App's settings revokes the Google authorization and immediately deletes the stored refresh token and playlist IDs.
  • Access can also be revoked at any time from the Google security settings page.
  • Posting records can be deleted at any time from the App's posting screen.
  • Deletion requests are completed within 30 days at the latest.
